🔍 Inspector Web desde el Móvil

Activa una consola de desarrollador (tipo DevTools) en cualquier página, sin ordenador.

0Escribe la URL que quieres inspeccionar

Muchas webs (footballia.eu incluida) bloquean cargarse dentro de un recuadro por seguridad, así que la forma fiable es abrirla directamente y usar el marcador desde ahí.

1Una vez cargada arriba, activa la consola con este botón

📱 Inspeccionar

En Chrome/Safari móvil: mantén pulsado este botón → "Añadir a marcadores" o "Compartir" → "Añadir a favoritos". Si tu navegador no deja arrastrar/guardar enlaces JS fácilmente, mira la alternativa manual más abajo.

2Ve a la web que quieres inspeccionar

Por ejemplo, tu clasificacion.html en GitHub Pages.

3Abre el marcador "📱 Inspeccionar" desde esa misma pestaña

Aparecerá un icono flotante en la esquina. Tócalo para abrir la consola: verás pestañas de Console, Elements, Network, Resources, etc — igual que en escritorio.

Si el bookmarklet no se deja guardar

Algunos navegadores móviles bloquean guardar enlaces javascript: como marcador directamente. Alternativas que funcionan seguro:

  • Kiwi Browser (Android): permite instalar extensiones de Chrome de escritorio, incluidas DevTools completas.
  • Chrome Android + PC: depuración remota vía chrome://inspect (requiere cable USB una vez).
  • Añadir Eruda manualmente: si controlas el código de tu web (como tus HTML de 1909 RSO), añade esta línea antes de </body> temporalmente:
    <script src="https://cdn.jsdelivr.net/npm/eruda"></script><script>eruda.init()</script>
